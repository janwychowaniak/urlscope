# Security policy

## Reporting a vulnerability

Please report vulnerabilities in urlscope privately, through GitHub's private
vulnerability reporting: open the repository's **Security** tab and choose
**Report a vulnerability**, or go to
<https://github.com/janwychowaniak/urlscope/security/advisories/new>.
Do not open a public issue for it.

Problems in the urlscan.io service itself belong to urlscan, not to this library.

## Supported versions

Only the latest release on PyPI receives security fixes.
